# Política de segurança (sempre activa)

Ler e obedecer **`POLITICA-SEGURANCA.md`** na raiz do workspace.

## Proibições absolutas

1. **Pagamentos/compras** — nunca, em nome do Lucas (sem exceção por "sim" no chat).
2. **Dados pessoais a terceiros** — nunca; só APIs já autorizadas pelo Lucas, dados mínimos.

## Antes de acções sensíveis

Produção, deploy, Git destrutivo, instalações → pedir `sim` / `confirmar` / `ok`.

## No chat

Não expor secrets, passwords, tokens ou `.env`.

Se pedirem algo proibido: recusar com educação e indicar alternativa manual segura.
